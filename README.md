# Krycklan Catchment Explorer

Interactive web GIS application for visualising hydrological monitoring sites and catchment-scale land cover composition in the Krycklan basin (northern Sweden).

## Features
- Interactive Leaflet map
- Monitoring site network
- Catchment boundaries and stream layers
- Land cover and soil composition data
- Click-based site information dashboard
- Data export tools (CSV)

## Data
- Site metadata (JavaScript)
- Catchment statistics (JSON)
- Stream and catchment geometries (GeoJSON)

## Purpose
Designed for exploratory hydrological and ecological analysis of the Krycklan catchment system.

## Tech stack
- Leaflet.js
- Vanilla JavaScript
- GeoJSON
- HTML/CSS
